# Udaipur Toloba — Privacy Policy

This repo hosts the public privacy policy page for the Udaipur Toloba
membership dues app (iOS & Android), served via GitHub Pages.

## Publishing

1. Push this repo to GitHub under your org (e.g. `udaipurtoloba/privacy-policy`).
2. In the repo, go to **Settings → Pages**.
3. Under **Build and deployment → Source**, select **Deploy from a branch**.
4. Branch: `main`, folder: `/ (root)`. Save.
5. GitHub publishes the page at:
   `https://<org-or-username>.github.io/<repo-name>/`

## Updating

Edit `index.html` directly and push — GitHub Pages redeploys automatically
within a minute or two. No build step required.
